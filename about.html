01 · what almond is

What Almond is

Almond Linux is an independent Linux distribution project focused on simplicity, stability, performance, and freedom. The initial operating system will be based on Debian. The long-term goal is for Almond to become a fully independent distribution of its own. Almond Linux is currently in early development.

Debian was chosen as the starting point for its stability, its huge package archive and its mature live-build tooling. Almond’s own work is planned to sit on top of that base: its branding first, then its desktop, and later a graphical installer.

Nothing has been released yet; a first test ISO has only booted in a virtual machine. The development page has the roadmap and shows exactly where the work stands.

02 · vision

Vision

Three goals, not three features.

Almond’s tagline names what the finished system should be. None of it is something you can use today, because there is nothing to install yet.

  1. Simple.

    A clean desktop with sensible defaults. Someone new to Linux should be able to get going without reading a manual.

  2. Powerful.

    The whole Debian package archive underneath, for people who want to go further.

  3. Yours.

    Free and open-source software, no tracking, and nothing you can’t change.

Together they add up to one aim: an operating system people choose on purpose.

03 · editions

Two editions

Almond is planned in two editions on the same Debian base: a large one for newer PCs and a little one for older and low-power 64-bit PCs.

AALDM is in progress as 0.1 ‘Marcona’; its first test ISO has booted in a virtual machine. AALLDM’s visual design is approved; no AALLDM system has been built.

Decided

  • AALDM comes first: 0.1 ‘Marcona’ is an AALDM release.
  • AALDM’s planned desktop is LXQt with the Openbox window manager on X11.

Still open

  • The desktop environment for AALLDM, which will be designed separately.
  • The minimum hardware for each edition.

One limit from the base

Debian 13 no longer supports installing on 32-bit PCs, so AALDM will need a 64-bit PC.

Where the codenames come from

Each named release takes its codename from a Spanish almond variety. Marcona, Largueta and Valencia were chosen on 14 October 2026. Releases after 0.3 have not been named yet.

06 · independence and privacy

Independence and privacy

Independent

Almond Linux is an independent project. It is not affiliated with Debian, Canonical, Red Hat, AlmaLinux or any other Linux organization.

Being planned on a Debian base does not make Almond part of Debian.

Private

This site sets no cookies and has no analytics or trackers. It loads its fonts from its own server, so every file a page needs comes from the same place as the page itself.

GitHub, which hosts the site, may keep standard server logs.
