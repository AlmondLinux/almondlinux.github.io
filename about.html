About Almond Linux

Almond Linux (short name: Almond) is an independent Linux distribution project. Its tagline is Simple. Powerful. Yours. It is currently in early development: nothing described here has been released.

Vision

  • Simplicity – sensible defaults and a clear system.
  • Stability – built on Debian Stable.
  • Performance – a lean, responsive desktop.
  • Freedom – open source, with no hidden tracking.

Names

AALLDM stands for “A All Large Linux Distro Model”. AALDM stands for “A All Large Distro Model”. They are the project’s development framework names.

Open source

Almond will be assembled from open-source software, mainly Debian packages. Each component keeps its original license and copyright. Almond does not claim ownership of upstream software.

Logo

The almond logo is the official visual identity of the Almond Linux project.

Independence

Almond Linux is not affiliated with Debian, Canonical, Red Hat, AlmaLinux, or any other Linux organization.
