01 · what is coming

What is coming

Four documents are planned. Three are published in the main repository, one of them as a first draft; the installation guide has not been written yet.

The first ISO is planned as Almond 0.1 ‘Marcona’, and none has been built yet, so the installation guide has to wait for something to install.

Planned documents
DocumentStatusPublished
Installation guideNot written yetOnce an ISO exists
Build instructionsFirst draftIn the main repository
Contribution guidelinesPublishedIn the main repository
Security policyPublishedIn the main repository

The main repository is github.com/AlmondLinux/almond-linux. The installation guide will join the others there once there is an ISO to install.

Until then, this site and the repository are the documentation.

02 · license

License information

Almond’s own files are released under the MIT License.

That covers Almond’s build configuration, scripts, documentation and the code of this website. You may use, copy, change and share them, including in your own projects, as long as you keep the copyright and license notice. The full text is in the LICENSE file of each repository.

The name and the logo

The Almond Linux name and the almond logo are not covered by the MIT License. They identify this project. Please do not use them in a way that suggests something is an official Almond release when it is not.

Upstream software

Almond is assembled mainly from Debian packages. Every upstream component keeps its original license and copyright, and Almond does not claim ownership of any upstream software.

Fonts on this site

This website uses three fonts, all self-hosted. Each one keeps its own license, and the full license texts are linked below.

04 · contact

Contact

There is no public contact address. GitHub is the way to reach the project.

Questions and bug reports go to the issue tracker of the main repository.

Security problems should be reported privately instead, never in a public issue: use “Report a vulnerability” on the repository’s Security tab, as its security policy describes.

The AlmondLinux organisation on GitHub is the project’s public home.
