01 · editions

Choose your edition

Almond is planned in two editions on the same Debian base. Pick the one that matches your PC. Neither can be downloaded yet, and which one is released first has not been decided.

Aiming big and modern, for newer PCs

AALLDM Edition

A All Large Linux Distribution Model

The large edition: a bigger, more modern desktop for newer PCs, with room for the nicer touches. Its desktop environment and minimum hardware have not been chosen yet.

░ No download yet Roadmap Follow on GitHub

Aiming light and quick, for older PCs

AALDM Edition

A All Little Distribution Model

The little edition: a lighter system for older and low-power PCs, meant to stay quick on hardware other systems have left behind. It will need a 64-bit PC, because Debian 13 no longer installs on 32-bit ones.

02 · releases

How releases will be published

Nothing has been released yet. When a release exists, this is how it will reach you.

  • It will appear on this page and on the Releases page of the main repository.
  • Each ISO will come with a SHA256 checksum file, so you can confirm that the file you downloaded is exactly the one the project published.

Release names come from Spanish almond varieties: 0.1 ‘Marcona’, 0.2 ‘Largueta’ and 0.3 ‘Valencia’. 0.5 and 1.0 are not named yet. See the full roadmap.

When a release exists

Checking a download

Open a terminal in the folder that holds the ISO and its SHA256SUMS checksum file, then run:

sha256sum -c SHA256SUMS

This reads the checksums listed in SHA256SUMS, calculates the checksum of each file you downloaded, and compares the two. A line ending in OK means the file matches what the project published. FAILED means it does not: delete that file and do not install it.

03 · safety

Stay safe

One rule, until the first release is announced here.

Until a release is announced on this page, any file calling itself an Almond Linux ISO did not come from this project.

Do not install it, however it reached you: a link, a forum post or a file someone shared. If in doubt, check this page.
