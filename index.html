About Almond

Almond Linux is an independent Linux distribution project focused on simplicity, stability, performance, and freedom. The first versions are planned to be based on Debian, with the possibility of becoming more independent in the future. Read more.

Our vision

Our long-term goal is a desktop operating system that is easy to start with, steady to rely on, and fully under the control of the person using it:

  • Simple – a clean desktop with sensible defaults, so a new user can get going without reading a manual.
  • Powerful – the full Debian package ecosystem underneath, for people who want to go further.
  • Yours – free and open-source software, no tracking, and nothing you cannot change.

Development roadmap

Every milestone below is planned; none is completed yet.

  • Almond 0.1 – First bootable Debian-based ISO. (planned)
  • Almond 0.2 – Custom Almond branding, wallpaper, themes, and system identity. (planned)
  • Almond 0.3 – Customized desktop experience. (planned)
  • Almond 0.5 – Graphical installer and testing. (planned)
  • Almond 1.0 – First stable public release. (planned)
