About Almond

Almond Linux is an independent Linux distribution project focused on simplicity, stability, performance, and freedom. The first versions are planned to be based on Debian, with the possibility of becoming more independent in the future. Read more.

Our vision

A system that is easy to start with, steady to rely on, and fully under the control of the person using it.
